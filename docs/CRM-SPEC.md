# CRM נינה סטודיו — אפיון (גרסה 1: אלבומים)

עודכן: 13.10.2026

## המטרה
מקום אחד שבו כל הלידים, הלקוחות וההזמנות של האלבומים מנוהלים — שמתעדכן לבד, אומר לי מה דורש אותי, ועונה לי על שאלות על העסק.
אתרים — בשלב מאוחר יותר, באותה מערכת (תיקי הלקוח והשאלונים כבר קיימים).

## עקרונות
1. **הנתונים נכנסים לבד.** הזמנות מוויקס, פניות מוואטסאפ, עגלות נטושות — בלי הקלדה.
2. **הסטטוס מתעדכן לבד** איפה שאפשר (תשלום, שליחת לינק, העלאת תמונות לדרייב).
3. **כל שלב יודע אצל מי הכדור** — אצלי, אצל הלקוחה, או ניטרלי (דפוס).
4. **המערכת היא המקור, השיטס הוא גיבוי.** עורכים רק במערכת; השיטס מתעדכן ממנה אוטומטית.
5. **הטלגרם הוא הממשק בדרכים.** סיכומים, התראות, אישורי הודעות ושאלות — דרך הבוט.
6. **מחשב קודם, מובייל אחר כך** — אבל בנוי כך שלא נשבר במסך קטן.

**שדה "משלוח":** ישיר מהדפוס / דרכי / איסוף. אם ישיר — מ"בדפוס" עוברים ל"במשלוח".

### מעברים אוטומטיים
| מה קרה | לאן עוברים |
|---|---|
| הזמנה שולמה בוויקס | עיצוב אישי/חתונה → ממתין לחומרים · טמפלט → ממתין לחומרים |
| הסוכן שלח לינק לדרייב | נשאר ממתין לחומרים, נרשם בציר הזמן |
| הועלו תמונות לתיקייה בדרייב | ממתין לעיצוב (הבוט שואל לאשר) |
| לקוחת טמפלט שלחה לינק לקבצים בוואטסאפ | הבוט שואל: "לבדוק או ישר להדפסה?" |
| נשלחה הודעת משלוח (ראו למטה) | במשלוח |
| אישרתי בטלגרם שהגיע | סגור |

### הודעת משלוח (סגירת פרויקטים)
1. הגר מנסחת פעם אחת תבנית: "היי {שם}, שמחה לעדכן שהאלבום מוכן! תקבלי SMS מ-HFD עם לינק למעקב, הוא יגיע אלייך בעוד יומיים-שלושה 💛". נשמרת ב-`messages.js`.
2. בטלגרם: "תשלח הודעת משלוח לנועה, דנה וטלי" → הבוט מראה למי בדיוק (שם + טלפון + הזמנה) ומבקש אישור אחד.
3. אחרי אישור: שולח בוואטסאפ, מעביר כל הזמנה ל"במשלוח", רושם בציר הזמן.
4. אחרי 4 ימים: "נועה, דנה, טלי — הגיעו?" → "כן" / "כולן חוץ מטלי" → סגור.
5. **אוטומטי מהמייל של דיפרינט:** סקריפט בחשבון הגוגל (Apps Script) בודק כל כמה דקות מיילים עם הנושא "איזה כיף הזמנתך ... בדיפרינט מוכנה".
   - מזהה את הלקוחה לפי "שם הפרויקט" + הטלפון בכתובת המשלוח, ומוצא את ההזמנה שלה ב"בדפוס".
   - אם כתובת המשלוח היא של הלקוחה → הבוט: "האלבום של דקל מוכן ונשלח אליה, לשלוח הודעת משלוח?"
   - אם כתובת המשלוח היא שלי → עובר ל"ממתין למשלוח".
   - שומר את מספר ההזמנה בדיפרינט על ההזמנה.
   - אם לא נמצאה התאמה בטוחה → הבוט שואל למי זה שייך.
6. "הגיע?" — הבוט שואל **אותי**, לא את הלקוחה.

התראת מעקב: "קיבלה הצעה" בלי תשובה 4 ימים → הבוט מציע הודעת פולואפ.

### מקורות לידים
1. **וואטסאפ** — מספר לא מוכר ששואל על אלבום → ליד חדש + הצעת תשובה לאישור בטלגרם.
2. **עגלות נטושות בוויקס** — מי שהתחילה הזמנה ולא סיימה.
3. **טפסים / אנשי קשר מהאתר.**
4. **אינסטגרם** — ידני: כפתור "ליד חדש", או העברה לבוט.
5. **לקוחות עבר** — הזדמנויות שהמערכת מזהה (שנה אחרי חתונה, לקוחה חוזרת וכו').

## תיק לקוחה
- פרטים: שם, טלפון, מייל, אינסטגרם, כתובת, מקור הגעה, תגיות, הערות.
- כל ההזמנות שלה (עם שלב, מוצר, מחיר, רווח).
- כל הלידים שלה.
- **ציר זמן**: כל שינוי שלב, הודעות שהסוכן שלח/קיבל, תשלומים, הערות — מי עשה ומתי.
- כפתורים: וואטסאפ, תיקייה בדרייב, הזמנה בוויקס.

## פרטי הזמנה
מוצר (עיצוב אישי קלאסי / פרימיום / חתונה / טמפלט + שם הטמפלט), נושא האלבום, גודל, מספר עמודים, מחיר ללקוחה, איפה שולם, קבלה הוצאה, עלות הדפסה (מחושבת לפי עמודים), שולם לדפוס, משלוח (ישיר/דרכי/איסוף), עלות משלוח, רווח נטו (מחושב), מספר הזמנה בוויקס, תיקייה בדרייב, שלב + מצב מיוחד, הערות.

## מסכים (מחשב)
1. **היום** — מה דורש אותי (לפי דחיפות), מי נתקעה אצל הלקוחה, לידים למעקב, מה נכנס אתמול.
2. **לקוחות** — מסד כל הלקוחות עם חיפוש וסינון (חוזרות, הזמנה פתוחה, מוצר), ובראש: כמה לקוחות, כמה חזרו, ממוצע ללקוחה. משם נכנסים לתיק.
3. **הזמנות** — טבלה גדולה עם סינון (שלב, מוצר, אצל מי, שנה) + תצוגת לוח לפי שלבים.
4. **לידים** — טבלה + לוח.
5. **תיק לקוחה** — כנ"ל.
6. **נתונים** — הכנסות ורווח לפי חודש, פילוח מוצרים, זמן ממוצע בכל שלב, לקוחות חוזרות, מקורות לידים. + תיבת "תשאלי".

## טלגרם (הבוט)
- **סיכום בוקר** (כל יום, 08:30): מה מחכה לי, ובראש — "ממתין להדפסה"; מי נתקעה; לידים לפולואפ; מה נכנס אתמול.
- **סיכום שבועי** (ראשון): הכנסות ורווח השבוע, השוואה לשבוע/חודש קודם, תובנה אחת ("אלבומים יושבים בממוצע 5 ימים בממתין להדפסה").
- **אישורים בלחיצה**: טיוטות תשובה ללידים, מעבר שלב שזוהה אוטומטית.
- **שאלות חופשיות**: "כמה הרווחתי בספטמבר?", "מי מחכה לתמונות?", "תעביר את נועה לבדפוס".

## ייבוא היסטוריה
מייבאים את 2024, 2025, 2026 (~480 הזמנות).
- לקוחות מאוחדות לפי טלפון (ואם אין — לפי שם, עם בדיקה ידנית).
- מיפוי סטטוסים: ממתין → ממתין לחומרים · נשלח להדפסה → בדפוס · תיקון / בהולד → מצב מיוחד · השאר כמו שהם.
- "עיצוב אישי" מ-2024/2025 → עיצוב אישי קלאסי.
- שורות בעייתיות (החזרים, שורות בלי שם, שורות ממוזגות, "עותק נוסף") → רשימת בדיקה שאני עוברת עליה פעם אחת.
- **שימי לב:** ב-2026 יש 19 הזמנות ב"נשלח להדפסה", חלקן מאוגוסט. כנראה רובן כבר נסגרו ולא עודכנו — נעבור עליהן ביחד בייבוא.

## השיטס כגיבוי
- הזמנה חדשה ממשיכה להיכנס כשורה בלשונית של השנה (כמו היום).
- שינוי שלב במערכת → מתעדכן בעמודת הסטטוס בשיטס.
- פעם בלילה — ייצוא מלא ללשונית "גיבוי מערכת".
- שינוי שנעשה ישירות בשיטס **לא** חוזר למערכת.
